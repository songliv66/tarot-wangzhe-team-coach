仓库提供 [GitHub Actions 配置示例](ci-example.yml)，启用后将运行 Python 3.9／3.12 的离线测试与 demo。本次 GitHub 连接缺少 workflow 权限，因此未启用自定义 CI；配置保存在 docs 作为示例，没有改动账户权限。38 项通过指本机结果，不代表远端 CI 已运行。维护者可自行把示例放到 `.github/workflows/ci.yml` 后启用。

公开的五段示例是预写模拟对话，不是模型基准分数。独立 Agent 验收使用另行给定的合成原始输入，不读取预写答案；其方案与脚本处理结果另外检查。单次通过不证明所有模型或所有任务稳定表现。
