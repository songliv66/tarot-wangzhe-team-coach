# 五个问题，把虚构队伍的赛训串起来

这组 Demo 展示同一支虚构“纸鸢队”从磨合、研究、BP、训练到复盘的连续用法。每一篇都有可复制的完整输入和一份预写示例答复，可以逐篇阅读，也可以挑一个问题试用。

**这是预写的模拟对话 Demo，不是模型实时运行记录、评分结果或真实战绩。**队名、队员、英雄池、赛事样本、时间戳和练习结果均为虚构。示例答复展示预期的组织方式与推理边界，不保证每次调用都会逐字输出同一内容，也不证明训练有效。

**离线示例未接入当前官方数据，第三方讲解未审阅。**文中的阵容与训练安排都是基于示例输入的条件计划；当前英雄机制、版本强度及完整真实比赛规则均未核实，不能当作当前版本攻略或正式比赛合法性结论。

## 哪些内容可以复用

可以复用问题的写法、证据分层、BP检查步骤、可缩放的时间安排和复盘指标。实际使用时把英雄池、出勤、目标、对手与比赛规则换成自己的真实输入；不应照抄示例中的“当前最适合阵容”。

研究中的四局来自四个互相独立的虚构系列，不是纸鸢队已经打过的四局，也不适用纸鸢队三局条件BP的跨局禁用状态。赵云与王昭君共现两次、一胜一负，仅有两次观察；不能拿来证明组合好坏，更不能写成官方KPL研究成果。

这些文件不包含真实队员账号、学校或公司名称、私人队伍记录、历史附件正文。不要把公开的示例目录用作真实队伍档案；实际训练材料保存在独立私有工作目录。
