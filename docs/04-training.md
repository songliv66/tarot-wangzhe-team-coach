# 问题四：只有90分钟，怎么练，临时变动怎么办？

> **预写模拟对话。**队伍、时间预算与安排全部虚构；以下是可调整的训练计划，不是已经执行的课表或实战成效。
>
> 离线示例未接入当前官方数据，第三方讲解未审阅。

## 示例答复

这次只回答两件事：“行动前是否收齐到场条件”和“分歧后是否只剩一个明确的最终决定”。先维持熟悉的位置与待练阵容，减少同时改变的变量；不以两场连胜之类结果作为训练验收。

### 90分钟安排

| 相对时间 | 安排 | 具体产出与责任 |
| --- | --- | --- |
| 0—10分钟 | 对齐今天目标、出勤和主副指挥 | 青禾复述集合确认流程；山雀复述接手条件；其余三人各说本晚有什么限制。指定一名轮换记录者，记录者同样参与练习，不承担完整逐秒记录 |
| 10—25分钟 | 三个简短桌面情境或可控练习 | 依次练“一人稍晚”“一人不能到”“两人意见相反”。每次走完报条件、收束、回应；找出一句容易混淆的口令并改短 |
| 25—65分钟 | 应用到可安排的自定义练习、练习赛片段或一段正常对局 | 记录少量关键集合事件：谁提出、五人回应是否齐、最后决定是什么。观察实际发生的事件，不为了凑次数强行接团 |
| 65—82分钟 | 复盘两至三个最有信息的事件 | 先复述材料，再分开事实、自述和分析。每人补充自己当时看到的条件；没有记录的部分写未知，不靠多数人记忆判定某人动机 |
| 82—90分钟 | 约定下一次继续验证的两件事 | 青禾确认最终用语与移交方式；记录者保存短笔记，队员核对有无误记；确定下次到场情况与是否需要补录像授权 |

25—65分钟是40分钟的应用窗口，**不保证能完成固定局数**。开局前按可控时长选择练习形式；如果选了完整正常对局，就要预留可能超时的安排，不能为了卡表中途退出。若无法保证90分钟内结束，应改用可控片段、桌面推演或事先约好的练习，而不是把后半段复盘必然挤掉。

每次应用只抓少量重要事件。记录者来不及记全时，标记缺失；不要写出并不存在的逐秒语音日志。

### 本次观察怎么记

一条事件笔记写四项即可：大致时间与来源、提出的意图、五人的到场回答、最终收束决定。比如“约第一个观察窗口，队员会后自述：月白说稍晚；是否其他四人已回应未记全”。这种笔记可支持继续追问，不能直接认定实际对局里所有人都听见了。

如果有经同意保留的录像或语音，记录可定位片段以便复查；没有就明确保留自述性质。本轮不需要收集账号、学校或公司信息。

### 临时只有60分钟

保留相同目标，缩减应用范围和复盘事件数量，不把所有环节硬塞进更小窗口。

| 相对时间 | 安排 |
| --- | --- |
| 0—7分钟 | 确认到场、限制、主副指挥与今天只练的两个动作 |
| 7—17分钟 | 只演两个情境：有人不能到、两条口令冲突 |
| 17—44分钟 | 一个可控应用窗口；不保证能打完一场完整对局，按实际可控程度选形式 |
| 44—55分钟 | 只复盘两个关键事件，分别说明记录来源与未知项 |
| 55—60分钟 | 留下下次的两项验证、确认出勤并保存短笔记 |

不要为了60分钟安排临时降低正常对局的参与承诺。若完整比赛已经开始且超时，应正常完成，并将复盘改到双方确认的时间；以后调整练习形式。

### 临时缺一人

默认不拿四人执行结果评价“五人协作是否合格”，也不自动邀请未经确认的人来读队伍资料。先确定本晚能练什么：

- 缺阵位置仍空着：用桌面情境或已授权的历史片段，四人分别报告条件，缺阵位置标“未知／未参加”，练主指挥怎样处理信息缺口。
- 能合法安排四人参与的可控练习：只练现有人员的信息交换，不把临时位置代打效果混入五人训练指标。
- 临时替补已由队伍确认：先说明任务、能用英雄与资料范围，重新确认职责；替补的数据单独标记，不与原五人样本直接合并。

若缺的是青禾，由山雀在开场明确接手本晚主指挥，而不是到局中再默默改变；若山雀缺席，青禾先承担主指挥，不随意推定其他人已经接任副指挥。

最后只保留两项可继续验证的观察：集合前五人的到场回答是否完整，以及同一决策窗口内的不一致口令是否得到明确收束。下一篇用三条虚构文字事件演示[怎样复盘并设下一轮指标](05-review.md)。
